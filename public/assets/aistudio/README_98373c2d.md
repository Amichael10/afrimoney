# Afrimoney brand kit

A directory of Africa’s fintech ecosystem.

## Colors
- Orange #FF4C00
- Charcoal #0E0E0E
- Off-white #F7F7F7
- Cloud #EAEAEA
- Peach #FFE6D9

## Typography
Recommended: Suisse Intl (Regular, Medium, Bold). Licensed separately. Alternative: Inter.

## Usage
Use primary on light backgrounds, reversed on dark backgrounds, and monochrome for single-color applications. Leave clear space equal to at least one quarter of the mark height. Use the square icon for social profiles and app icons.

Assets are transparent raster PNGs extracted from the approved generated logo, not original editable vector artwork. The Africa cutout is transparent.
